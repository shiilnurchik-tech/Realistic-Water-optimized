# Realistic Water — Modified Version

> This repository contains a **modified version** of the original Realistic Water mod, created by **Skaffy**. It is a modification/fork and is **not the original mod**. Original project: [github.com/sskaffy/Realistic-Water](https://github.com/sskaffy/Realistic-Water).

A Minecraft mod that adds the realistic waters and sands from Blender animations.

#

How to use:

1. Download the latest modified version from: https://github.com/shiilnurchik-tech/Realistic-Water-optimized/releases/latest
2. Install Fabric (Tutorial: https://docs.fabricmc.net/players/installing-fabric/)
3. Put the mod to the mods folder
4. Open the game and set the Graphics API in the Video Settings to Vulkan and then restart the game
5. Place down a ball of water with "/water ball"
6. Or go in your Creative inventory and get a "Realistic Water Bucket" or "Realistic Lava Bucket"
7. Spawn lava with "/water lava" or "/water ball lava [size]"; remove with "/water remove lava"

## Automated releases
GitHub Actions builds the mod with Java 25 and publishes the jar to this fork's Releases when source/build files change on `26.3-*` and `arena/**` branches. The release tag includes the mod version from `gradle.properties` and a source-tree ID; bump `version` there when starting a new mod version. Documentation-only changes do not create a new release.
